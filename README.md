# Nocturnal Character Creator

A browser-based character creator for **Nocturnal: A Modern Ghost-Hunting RPG**.

This tool allows players to create and manage investigators for Nocturnal, including Attributes, Skills, Awakening, psychic abilities, Tracks, and active case investigation notes.

---

# Features

- Full investigator character creation
- Attribute allocation system
- Awakening system integration
- Skill assignment tracking
- Psychic ability selection and reference
- Dynamic Track calculation
  - Stress
  - Exposure
  - Attention
  - Corruption
- Current case investigation notes
- Pattern tracking
  - Anchor
  - Feed
  - Trigger
- Save and load characters locally in browser
- JSON export support
- Printable character sheet layout
- Mobile-friendly responsive design
- Atmospheric Nocturnal-themed interface

# Design Goals

The Nocturnal Character Creator was designed to support:
- Investigation-focused gameplay
- Fast reference during play
- Pressure and consequence tracking
- Atmospheric presentation
- Easy onboarding for new players

The interface intentionally avoids traditional fantasy RPG styling in favor of a more grounded investigative horror aesthetic.

---

# About Nocturnal

*Nocturnal: A Modern Ghost-Hunting RPG* is an investigative horror tabletop RPG about supernatural Patterns, escalating pressure, and the consequences of interfering with things beneath reality that refuse to stay buried.

Most people call them hauntings.

Investigators learn something different.
